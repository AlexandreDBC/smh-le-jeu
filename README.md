# SMH Le Jeu

Jeu d'aventures en terminal se deroulant sur le campus de l'Ensimag.
Le joueur explore des bâtiments et des rues, ramasse des objets (armes, armures, clefs, nourriture),
gère son inventaire et tente de découvrir un trésor.

Projet réalisé dans le cadre du cours **Analyse et Conception Objet de Logiciels** — Grenoble INP Ensimag, 2ème année ISI (2025-2026).

## Compilation et execution

```bash
# Compiler le projet
make compile

# Lancer le jeu
make run

# Lancer les tests
make test

# Nettoyer les fichiers compilés
make clean
```

La bibliothèque Lanterna (`lib/lanterna-3.2.0-alpha1.jar`) est incluse dans le dépôt.
La bibliothèque Junit (`lib/junit-platform-console-standalone.jar`) est incluse dans le dépôt.
